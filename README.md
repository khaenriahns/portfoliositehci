## Project Overview

This is a single page responsive portfolio website created as part of the WEEK06 HCI Lab Assignment. The website showcases my digital artwork, character designs, illustrations, and creative skills.

The website is built using HTML and CSS, featuring a minimalist monochromatic design with bold typography and a responsive layout.

- **Portfolio Website:** [Click Here](https://khaenriahns.github.io/portfoliositehci/)
- **Website Design:** [Click Here](https://canva.link/p8rinr360r0c41y)

## Purpose

The goals of this project are to:

- Practice HTML and CSS web development.
- Apply responsive web design techniques.
- Learn how to structure and style a webpage using semantic HTML.
- Showcase my artwork, character designs, and illustrations.
- Create an accessible platform for potential clients to view my work and contact me.

## Target Audience

This portfolio is designed for:

- **Potential Clients:** Individuals interested in commissioning character designs or illustrations.
- **Fellow Artists:** Artists interested in exploring my creative works and artistic style.
- **Creative Professionals:** Individuals seeking potential artistic collaborations.
- **General Visitors:** Anyone interested in digital art, original characters, and illustration.

## Modifications Used

- **HTML5** – Website structure and content.
- **CSS3** – Styling, layout, and responsiveness.
- **CSS Flexbox** – Navigation and content alignment.
- **CSS Grid** – Portfolio gallery and responsive layouts.
- **Media Queries** – Adjusting the website layout for different screen sizes.
- **Google Fonts** – DM Sans, Shrikhand, and Playfair Display.

## Layout & Sections

The website includes the following sections:

- **Header** – Artist logo and navigation links to the About, Portfolio, and Contact sections.
- **Home** – Large introductory heading, tagline, and three artistic service categories.
- **About Me** – Short personal introduction and overview of my artistic interests.
- **Skills** – Character Design, Illustration, and Concept Art.
- **Portfolio** – Gallery displaying previous artwork and creative projects in a grid layout.
- **Contact** – Contact information for commissions, inquiries, and collaborations.
- **Footer** – Links to email and social media platforms, including Twitter/X, Instagram, VGen, and LinkedIn.

## Design & Color Scheme

The website follows a minimalist aesthetic to emphasize the images and typography.The primary colors used are monochromatic with strong hints of blues. The typography combines modern sans-serif fonts with bold, decorative serif fonts to create a distinctive visual identity.

## Responsiveness

The website is designed to accommodate different screen sizes:

- **Desktop** – Full navigation, multi-column layouts, and an expanded portfolio gallery.
- **Mobile** – Vertically stacked service categories and a simplified gallery layout.

Responsive design is achieved using CSS Flexbox, Grid, media queries, and flexible sizing properties such as `clamp()` and percentages.
